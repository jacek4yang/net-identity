      Activating a profile can request the egress IP from ipwho.is. A proxied profile shows that provider the proxy address. A direct profile shows it your own public IP, and only after you allow that collection. The location picker uses a local coordinate grid with no map imagery or external tile requests. Coordinates and all map interactions work offline. No telemetry and no remotely loaded code.

      Page-level geolocation and timezone changes are compatibility shims. They are observable by sophisticated page scripts and are not a claim of fingerprinting invisibility.
