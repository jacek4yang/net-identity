      Current state

      Activating a profile can request the egress IP from ipwho.is. A proxied profile shows that provider the proxy address. A direct profile shows it your own public IP, and only after you allow that collection. Map tiles, while this page is open, are images from tile.openstreetmap.org. The tile address reveals the area on screen. No telemetry and no remotely loaded code.

      Page-level geolocation and timezone changes are compatibility shims. They are observable by sophisticated page scripts and are not a claim of fingerprinting invisibility.
