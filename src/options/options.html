      Automatic profiles request the active proxy egress IP from a third-party GeoIP provider (ipwho.is) over HTTPS. That provider sees the proxy's public IP, never this browser's real one. No telemetry, no analytics and no remotely loaded code.

      Page-level geolocation and timezone changes are compatibility shims. They are observable by sophisticated page scripts and are not a claim of fingerprinting invisibility.
