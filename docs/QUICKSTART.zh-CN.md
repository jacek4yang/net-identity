# 快速配置、迁移与排错

[English](QUICKSTART.md) · [项目介绍](../README.zh-CN.md)

本文的弹窗快速添加和双语界面属于候选分支功能，不代表 AMO 已经发布。请自备代理服务器。

## 添加并使用代理

1. 打开 Net Identity，点击“添加代理”，填写主机和端口。
2. 核对协议。裸地址使用界面中选定的 SOCKS5；明确的 URL 协议优先。
   例如 `127.0.0.1:10808`、`http://proxy.example.com:8080`、
   `socks5://[2001:db8::1]:1080`。扩展不会联网猜测协议。
3. 需要认证时展开会话认证，分别填写用户名和密码，不要放进 URL。Firefox 的 SOCKS4
   不支持认证。
4. “保存”只保存配置，“保存并启用”会明确应用。地址格式正确不代表代理已经连通。
5. 分别查看线路状态和身份诊断。线路启用不代表 GeoIP 成功，也不代表所有框架都应用了兼容层。

新代理默认启用仅代理 WebRTC、自动位置与时区，以及 SOCKS 代理 DNS。已有配置保留原设置。
严格 WebRTC 可能影响不支持代理 TURN/TCP 的通话，可在理解隐私代价后明确调整。
这不等于接管浏览器或操作系统的全部流量。

## 日常使用

点击配置即可切换；按名称、主机、端口或协议搜索不会切换线路。
“关闭”释放身份与 WebRTC 控制；“浏览器／系统路由”沿用现有路由，其中也可能配置了其他代理。

设置页的“保存”保存修改，“应用”启用已保存版本；未保存的编辑仍留在表单中。
刷新使用已应用配置，复制不会携带认证信息。退出 Firefox 后会话凭据丢失，需要重新填写
用户名和密码并应用。保存时两项留空则保留本次会话已有的凭据。

语言设置独立于网络身份。高级设置提供 DNS、绕过规则、手动坐标、时区和 WebRTC 控制。
在线地图按需加载，加载时向服务商披露当前公网 IP 和查看区域；本地网格及坐标输入可离线使用。

## 从其他扩展迁移

先保留原配置，将协议、主机、端口复制到新配置，认证信息单独填写。
验证新线路时避免多个扩展争夺代理控制权。核对观察到的出口与诊断状态，再停用旧方案。

目前不宣称支持 FoxyProxy 或 SwitchyOmega 文件导入，不会读取其他扩展的私有存储。
不要将含认证信息的导出文件上传到公开 Issue。

## 常见问题

- **保存后没变化？** 保存不会启用。点击配置或应用已保存版本。
- **代理能用，但身份部分生效？** GeoIP 可能独立失败。查看原因、网络连接及必要许可，
  不要仅凭 GeoIP 失败就判断代理绕过。
- **重启浏览器后不能联网？** 会话密码已丢失。重新填写匹配凭据并应用；缺少凭据不会静默直连。
- **地图是空的？** 默认是离线坐标网格。在线数据需要明确加载和可用线路，影像失败仍能输入坐标。
- **通话无法连接？** 严格的仅代理 WebRTC 需要可用的代理 TURN/TCP 通道。降低限制有隐私代价。
- **为什么 Direct 仍经过代理？** 它保留 Firefox 和系统原本的代理设置。
- **为什么仍有 Mozilla 安全提示？** 签名或普通审核不等于主动安全监控，也不等于 Recommended 认证。

## 安全地反馈问题

附上扩展／Firefox 版本、系统、协议、复现步骤、预期与实际行为，以及脱敏后的诊断代码。
删除用户名、密码、令牌、个人 IP 和私有地址。安全漏洞请按 [SECURITY.md](../SECURITY.md) 私下报告。
