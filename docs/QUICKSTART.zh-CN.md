# 快速配置、迁移与排错

[English](QUICKSTART.md) · [项目介绍](../README.zh-CN.md)

本文描述 1.2.0 源码，当前已发布版本请查看 AMO。请自备代理服务器；扩展不提供代理或 VPN 服务。

## 添加并使用代理

1. 打开 Net Identity，点击“添加代理”，填写主机和端口。
2. 核对协议。裸地址使用界面中选定的 SOCKS5；明确的 URL 协议优先。
   例如 `127.0.0.1:10808`、`http://proxy.example.com:8080`、
   `socks5://[2001:db8::1]:1080`。扩展不会联网猜测协议。
3. 需要认证时展开认证选项，分别填写用户名和密码，不要放进 URL。Firefox 的 SOCKS4
   不支持认证。
4. 完整地址会在保存前自动通过草稿代理检测出口 IP、大致位置和时区，不改变现有浏览线路，
   也不保存草稿配置或凭据。设置页中“公网 IP／GeoIP”设为禁用时不安排检测；弹窗快速添加
   按设计自动预览。
5. “保存”只保存配置，“保存并启用”保存当前表单并启用。地址有效或检测成功都不代表已经启用。
6. 分别查看线路状态和身份诊断。线路启用不代表 GeoIP 成功，也不代表所有框架都应用了兼容层。

新代理默认启用仅代理 WebRTC、自动位置与时区，以及 SOCKS 代理 DNS。已有配置保留原设置。
严格 WebRTC 可能影响不支持代理 TURN/TCP 的通话，可在理解隐私代价后明确调整。
这不等于接管浏览器或操作系统的全部流量。

## 日常使用

点击配置即可切换；按名称、主机、端口或协议搜索不会切换线路。
“关闭”释放身份与 WebRTC 控制；“浏览器／系统路由”沿用现有路由，其中也可能配置了其他代理。

设置页的“保存”保留修改而不切换线路；“保存并启用”保存并启用当前可见表单。点击已有配置
会应用它的已保存版本。刷新使用已应用配置，复制不会携带认证信息。保存时认证两项留空则
保留已有凭据。

未启用保险库时，退出 Firefox 后会话凭据丢失，需要重新填写用户名和密码并启用。
启用“保护已保存的配置”后，配置、已保存凭据与已应用凭据会通过主密码加密持久保存。
完整重启后解锁以恢复原先已应用的配置，不会自动应用较新的已保存编辑。请将加密备份
保存在 Firefox 配置目录之外；主密码无法重置，备份仅可恢复到空白安装。
详见[加密存储与恢复](ENCRYPTED-VAULT.md)。

语言设置独立于网络身份。高级设置提供 DNS、绕过规则、手动坐标、时区和 WebRTC 控制。
在线地图首次明确加载时向 OpenFreeMap 披露网络可见的 IP 和查看区域，并记住后续打开
可见地图时自动加载的偏好。每次打开仍检查当前线路、认证与许可。“卸载地图”或取消自动
加载会清除该偏好；本地网格及坐标输入可离线使用。

## 从其他扩展迁移

先保留原配置，将协议、主机、端口复制到新配置，认证信息单独填写。
验证新线路时避免多个扩展争夺代理控制权。核对观察到的出口与诊断状态，再停用旧方案。

目前不宣称支持 FoxyProxy 或 SwitchyOmega 文件导入，不会读取其他扩展的私有存储。
不要将含认证信息的导出文件上传到公开 Issue。

## 常见问题

- **保存后没变化？** 保存不会启用。点击已保存配置，或用“保存并启用”应用当前表单。
- **代理能用，但身份部分生效？** GeoIP 可能独立失败。查看原因、网络连接及必要许可，
  不要仅凭 GeoIP 失败就判断代理绕过。
- **重启浏览器后不能联网？** 已启用保险库时请先解锁；否则需重新填写会话凭据并“保存并启用”。
  缺少凭据时，扩展可观察的普通流量不会静默改为直连。Firefox 受保护的服务请求存在控制边界，
  要确保账户身份，代理服务器必须拒绝匿名访问。
- **忘记主密码？** 没有密码重置服务，备份也需要同一主密码。请独立妥善保存密码和加密备份。
- **地图是空的？** 初始是离线坐标网格。在线数据需要首次明确加载或记住的加载偏好，并通过
  当前线路与许可检查。影像失败仍能输入坐标。
- **通话无法连接？** 严格的仅代理 WebRTC 需要可用的代理 TURN/TCP 通道。降低限制有隐私代价。
- **为什么 Direct 仍经过代理？** 它保留 Firefox 和系统原本的代理设置。
- **为什么仍有 Mozilla 安全提示？** 签名或普通审核不等于主动安全监控，也不等于 Recommended 认证。

附上扩展／Firefox 版本、系统、协议、复现步骤、预期与实际行为，以及脱敏后的诊断代码。
删除用户名、密码、令牌、个人 IP 和私有地址。安全漏洞请按 [SECURITY.md](../SECURITY.md) 私下报告。
